# GUI planning

`gui/` przechowuje obecnie zatwierdzone plany API i specyfikacje modułów
mikrofrontendowych. Nie jest jeszcze aplikacją frontendową ani pakietem do
budowania.

Plany pozostają w repozytorium, ponieważ opisują kontrakt między przyszłym GUI
a backendem. Implementacja frontendowa powinna powstać w osobnym pakiecie lub
repozytorium, gdy zostanie wybrany właściciel i narzędzia budowania.

Wygenerowane obrazy, zrzuty kodu i inne materiały robocze nie należą do tego
katalogu; są ignorowane przez Git. Braki backendu opisane w planach są
niezrealizowanymi założeniami, a nie aktywnymi issue.
