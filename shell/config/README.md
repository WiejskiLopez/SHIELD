# Konfiguracja certyfikatów mTLS

Ten katalog przechowuje tymczasowy, badawczy CA (`ca.crt` i `ca.key`) oraz testowe certyfikaty usług używane lokalnie i w demonstracjach mTLS. Klucze nie mogą być używane jako sekrety produkcyjne.

Materiały certyfikatów pozostają wersjonowane zgodnie z `docs/security/transport-security.md`. Produkcyjne dane uwierzytelniające muszą być dostarczane przez bezpieczny secret manager.
